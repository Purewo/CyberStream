# CyberStream PC 1.21.1-pc.2

跟 1.21.1-pc.1 比，本次发布是**纯修补型版本**——把上版用户在真实场景里碰到的几处卡顿、过滤失效、字幕引发的卡死都收拾了。

## 下载选哪个？

| 安装包 | 适合谁 | 大小 |
|---|---|---|
| **`CyberStream_1.21.1-pc.2_lite_x64.msi`** | 已经有自部署后端（NAS / VPS / docker）的用户 | ~93 MB |
| **`CyberStream_1.21.1-pc.2_full_x64.msi`** | 想开箱即用的小白用户、单机自用 | ~120 MB |

`full` 把后端打成 sidecar 进程一起捆绑进来，双击安装就有完整本地后端，不需要单独装 Python / 配 systemd。`lite` 是纯 webview shell，连远程 API。

## 主要变化

### 字幕加载不再卡死视频（重要）

之前在带远程外挂字幕的资源上，开播头 30 秒经常出现「画面冻 / 只剩声音」的现象——根因是 mpv 的 `sub-add` 在主循环里**同步阻塞**等字幕下载，4K HDR / Atmos 资源上字幕轨道又多又大，整个事件循环被锁死直到下载完成。改成异步 `sub-add async`，字幕在后台线程里下，视频该播播。

### 库筛选「地区 / 年份 / 类型」全部生效

之前 `/api/v1/libraries/{id}/movies` 这条路径忽略了 `country / year / genre` 三个参数，前端切任何标签返回的列表都不变。后端补齐了通用筛选条件，附带回归测试。

附加：年份选「**更早**」之前是字面量传给后端，后端不认就静默返回全部；改成翻译成 `0-<最早显示年份-1>` 区间——年份列表没截断时传不可能命中的 sentinel，符合「应该没有」的语义。

### 全屏 3 秒后鼠标会跟着控制栏一起隐藏

之前 idle 后控制栏渐隐了，但鼠标停在原位不消失。原因是控制栏内层 div 强制了 `pointer-events-auto`，把父级的 `cursor-none` 接管了。修成 `showBottomControls` false 时整层 `pointer-events-none`，事件穿透回 video 容器。

### 后端 sidecar 探活不再阻塞主线程

`full` 包之前在 `setup()` 里同步等后端最长 30 秒就绪，期间窗口卡死。改成 spawn 后立刻返回、健康检查搬到后台命名线程；超时只 log 一行 warn，前端首请求自然 5xx。同时 `cmd.spawn()` 失败也降级到 webview-only 模式（之前会让窗口闪退）。

### lite 包默认后端置空

之前默认值是 `127.0.0.1:49152`（full 包预期的本地端口），lite 用户首启会卡在「连不上」加载页。改成默认空字符串，首启自动跳到「设置 → 后端服务器」。

## 已知坑

- `full` 包冷启动需要等 sidecar PyInstaller 解包 + Flask init + DB schema 初始化（约 6-8 秒），期间窗口空白。第二次起会更快（OS 缓存）。
- 「更早」筛选对未截断的年份列表会返回 0 部，这是有意设计——没有真正"更早"的年份就不该出结果，不再像之前那样静默退化成「全部年份」。

## 升级指南

从 `1.21.1-pc.1` 升级：直接装新 MSI 即可。配置（后端地址 / 代理 / TMDB token）以 webview localStorage + `.env.local` 为准，不会丢。

注意：本版的 lite 默认后端从 `127.0.0.1:49152` 改成了空字符串。**已经在 1.21.1-pc.1 里配过后端地址的用户不受影响**——localStorage 里的自定义值优先。
