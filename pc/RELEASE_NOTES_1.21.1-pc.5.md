# CyberStream PC 1.21.1-pc.5

跟 1.21.1-pc.4 比，本次是**云盘播放体验**版本——原生播放器接入夸克 / UC / 阿里云盘的云端转码清晰度切换，外部播放器（PotPlayer / VLC）补上 User-Agent 改写，选集面板按网页端做了分段。

## 下载选哪个？

| 安装包 | 适合谁 | 大小 |
|---|---|---|
| **`CyberStream_1.21.1-pc.5_lite_x64_setup.exe`** | 已有自部署后端（NAS / VPS / docker）的用户 | ~37 MB |

本次只发 **lite**。`lite` 是纯 webview shell，连你自己的远程后端。完整版（含本地后端 sidecar）因为后端依赖 AList / OpenList 等外部组件不便随包分发，本轮暂不提供——需要本地后端的用户请自行部署后端，再用 lite 客户端进「设置 → 后端服务器」填地址。

## 主要变化

### 原生播放器云端转码清晰度切换

夸克 / UC / 阿里云盘的资源现在能在内嵌 mpv 播放器里切清晰度：

- 播放控制栏新增**清晰度菜单**（仅云端转码资源出现），「原画（原始文件）」置顶 + 后端返回的各转码档位（夸克 `low/normal/high/super/2k/4k`、阿里 `ld/sd/hd/fhd/qhd/4k`，档位因来源而异）
- **首帧默认走原始文件**（画质最高、不经转码），清晰度切换是按需选项
- **切档保留进度**：换清晰度时从当前播放位置续播，不回到开头（区别于换集——换集从头开始并自动切回原画）
- 完全按后端 `playback.cloud_transcode` 字段分发，不硬编码网盘类型或清晰度枚举，后端将来加档位前端自动适配

### 外部播放器 User-Agent 改写

部分云盘（如百度网盘）的直链要求特定 User-Agent，否则直链返回 403。但 PotPlayer / VLC 这类外部播放器从命令行启动时没法传 HTTP header。

本版在客户端内起一个 **本地媒体代理**（绑定 `127.0.0.1` 随机端口），把 stream URL 包一层、补上正确 UA 再转发给外部播放器。代理启动失败不致命，会降级回原始 URL（百度外播会 403，其他云盘正常）。

### 选集面板分段

剧集很多时（动辄几十上百集），选集网格现在按每段 30 集分页（`1-30` / `31-60` …），跟网页端一致。换集时网格自动翻到对应段。

## 已知坑

- 安装器**未数字签名**，Win SmartScreen 会弹"未知发布者"警告，点「更多信息 → 仍要运行」继续
- lite 版首次启动需自己进「设置 → 后端服务器」填后端地址，否则默认连 `127.0.0.1:49152` 大概率连不上
- 百度网盘**网页内播放**仍可能失败（后端直链 sign error，与客户端 UA 无关）；外部播放器经本地代理改写 UA 后可正常

## 升级指南

1. **从 pc.4 / pc.3 升级**：先用 Win 设置 → 应用 → 卸载旧版 → 双击新 setup.exe。卸载向导问要不要清空用户数据时**选否**，后端地址 / 库设置就保留下来
2. **全新安装**：双击 `_lite_x64_setup.exe`，首次进「设置 → 后端服务器」填你的后端地址
