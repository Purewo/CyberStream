# CyberStream PC 1.21.1-pc.3

跟 1.21.1-pc.2 比，本次发布是**易用性+体验**型小版本——把扫描首启的隐形坑、原生播放器音轨信息缺失、删除媒体库藏得太深、在线字幕拉取的契约错配都收拾了。

## 下载选哪个？

| 安装包 | 适合谁 | 大小 |
|---|---|---|
| **`CyberStream_1.21.1-pc.3_lite_x64.msi`** | 已经有自部署后端（NAS / VPS / docker）的用户 | ~93 MB |
| **`CyberStream_1.21.1-pc.3_full_x64.msi`** | 想开箱即用的小白用户、单机自用 | ~280 MB |

`full` 把后端打成 sidecar 进程一起捆绑进来，双击安装就有完整本地后端，不需要单独装 Python / 配 systemd。`lite` 是纯 webview shell，连远程 API。

## 主要变化

### 扫描前 TMDB Token 守卫

之前没配 TMDB Token 直接点扫描，扫描器一秒结束、库里全是兜底元数据，新装小白完全不知道发生了什么。这版在三处入口（媒体库扫描、存储源扫描、扫描刮削模态框开启刮削时）都加了守卫：未配置 token 时直接弹提示，跳转「设置 → 系统配置」让用户先配，避免静默走进死链。

### 原生播放器音轨细节按 PotPlayer 风格展示

之前音轨菜单只显示文件名，所有 9 条音轨长得一模一样根本没法选。改成解析 mpv 的 `audio-channels / demux-samplerate / demux-bitrate`，显示成 `#1 · eng · TRUEHD · 7.1 · 48.0 kHz`、`#2 · eng · DTS · 7.1 · 48.0 kHz` 这种细节列。文件名挪到 hover 提示，鼠标悬停才显示完整名字。字幕菜单的截断行也加了 hover 提示。

### 媒体库一键删除

之前删除媒体库的按钮藏在「编辑设置」弹窗的左下角红色 DELETE 按钮里，用户找不到。每张媒体库卡片右上角现在直接挂一个垃圾桶图标，hover 变红，点了走原本的二次确认流程。

### 在线字幕预览/绑定契约对齐

后端 `b1fd8be` 之后字幕搜索结果改成 `items[].downloads[]` 多下载源结构。前端预览/绑定路径同步改写，把 `candidate_id + download_index` 透传给下载接口。后端 502 错误信息也直接 toast 透传，不再吞成「字幕预览失败」一句。

### 右键菜单加了海报模糊背景

详情页的右键菜单分割线上方现在渲染一层目标海报的高斯模糊背景（28px blur · scale(1.4) · 渐变遮罩），跟正下方的菜单项有视觉层次。不会盖住任何菜单项。

## 已知坑

- `full` 包冷启动需要等 sidecar PyInstaller 解包 + Flask init + DB schema 初始化（约 6-8 秒），期间窗口空白。第二次起会更快（OS 缓存）。

## 升级指南

从 `1.21.1-pc.2` 升级：直接装新 MSI 即可。配置（后端地址 / 代理 / TMDB token）以 webview localStorage + `.env.local` 为准，不会丢。
