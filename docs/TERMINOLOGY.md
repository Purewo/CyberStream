# CyberStream 术语表

本文档只规范中文展示和沟通用词，不改变现有 API 路径、字段名、数据库表名或 Python 类名。为了兼容前端和历史数据，`Library`、`StorageSource`、`source_id`、`library_id` 等英文契约名继续保持不变。

## 核心叫法

| 统一中文名 | 对应后端契约 | 含义 | 不再优先使用的旧称 |
| --- | --- | --- | --- |
| 挂载点 | `StorageSource`、`source_id`、`/api/v1/storage/sources` | 一个本地目录、WebDAV、AList/OpenList 或托管云盘接入点。它描述“文件从哪里来”。 | 存储源、存储节点、来源 |
| 专辑 | `Library`、`library_id`、`/api/v1/libraries` | 用户创建的内容分组。专辑通过绑定目录从一个或多个挂载点收录内容。它描述“这些内容归到哪里看”。 | 逻辑资源库、资源库、媒体库分区 |
| 绑定目录 | `LibrarySource`、`root_path` | 专辑和挂载点之间的绑定关系，可限定挂载点下的具体目录。 | 来源绑定、目录绑定、媒体库绑定 |
| 影视库 | `/api/v1/movies` | 全局已发布影视目录。待审批和隐藏内容默认不出现在这里。 | 总媒体库、普通媒体库 |
| 待审批池 | `catalog_visibility.status=pending_review` | 刮削质量可疑、需要人工确认后才能发布到影视库的条目。 | 待处理、待审资源 |
| 其他视频 | `/api/v1/other-videos` | 更适合手工归档的非标准视频入口，不等同于待审批池或专辑。 | 其他资源、脏数据池 |
| 媒体文件 | `MediaResource`、`resource_id` | 实际可播放文件或剧集资源。 | 资源、视频资源 |

## 使用原则

- 前端按钮、标题、Toast、空状态和帮助文案统一使用“挂载点 / 专辑 / 绑定目录”。
- 后端 API、数据库和类型名不做破坏性重命名；需要解释时写作“挂载点（`StorageSource`）”“专辑（`Library`）”。
- “媒体库”只用于全局影视库或用户能理解的泛称，不再指代用户新建的 `Library`。
- “资源库”作为历史文档旧称保留在兼容说明里，新文案优先写“专辑”。
- “存储源”“存储节点”作为历史 API/代码旧称保留在兼容说明里，新文案优先写“挂载点”。
